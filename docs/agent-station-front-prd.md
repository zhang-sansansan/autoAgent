版本：v2.0  
日期：2026-08-19  
状态：已确认

参考项目：`ai-agent-station-front/`

## 1. 文档概述

本文档定义 `ai-agent-station-study-ann` 配套前端的全量 UI 与交互重构需求。重构后的产品命名为 **ANN Agent Studio**，面向 AI 开发与运维团队，统一承载 Agent 编排、资源配置、装配、对话调试与资源统计查看。

本次重构保留现有页面、路由、业务能力、后端接口和数据结构，不修改后端与数据库。参考项目用于借鉴成熟的信息结构和功能组织，不复制其品牌与视觉表现。

## 2. 背景与问题

现有前端已覆盖 Agent 与资源管理的主要能力，但各页面视觉和交互缺少统一产品语言，信息层级、状态反馈和高频操作体验仍有提升空间。参考前端提供了较完整的页面结构，但其视觉风格不能直接代表当前项目的独立品牌。

本次重构需要解决以下问题：

- 建立独立、统一且可持续扩展的 ANN Agent Studio 品牌界面。
- 在深色科技感和长时间使用舒适度之间取得平衡。
- 统一导航、列表、表单、弹窗、状态和错误反馈。
- 保证现有 13 个页面及特有业务操作完整可用。
- 确保所有展示数据来自现有后端，不以 Mock 数据伪造业务能力。

## 3. 产品定位

### 3.1 产品名称

**ANN Agent Studio**

产品使用纯文字字标，不设计独立图形 Logo。

### 3.2 产品定位

面向 AI 开发人员、Agent 配置人员和平台运维人员的智能体开发工作台，帮助用户完成：

- 查看 Agent 与各类资源数量概况。
- 创建、维护和装配 Agent。
- 可视化编排 Agent 流程。
- 管理模型、Prompt、Advisor、MCP 和 RAG 等资源。
- 通过流式对话调试 Agent。
- 管理平台登录用户。

### 3.3 首要使用场景

产品首要服务于日常开发与运维工作。设计优先级依次为：

1. 信息清晰与操作正确。
2. 高频任务效率。
3. 长时间使用舒适度。
4. 克制且具有品牌辨识度的科技感。

## 7. 全局视觉规范

### 7.1 视觉方向

全站采用 **Obsidian Signal** 深色视觉，不提供浅色主题切换。

- 主背景使用深黑与深蓝黑，避免大面积纯黑造成层级丢失。
- 主强调色使用电光紫，辅助信号色使用青色。
- 成功、警告、失败分别使用低饱和绿、琥珀色和红色。
- 卡片使用轻微透明层次、细描边和克制阴影。
- 发光效果只用于关键状态、主操作和焦点反馈。
- 不使用大面积炫彩渐变、过度玻璃化或持续闪烁动画。

### 7.2 品牌与文字

- 左上角和登录页使用 `ANN Agent Studio` 纯文字字标。
- 不提供独立图形 Logo。
- 正文强调清晰与紧凑，核心指标数字强调快速识别。
- 状态不得只依赖颜色表达，必须同时提供文字或图标。

### 7.3 动效

- 页面切换使用短时淡入与轻微位移动效。
- 按钮、菜单和卡片仅使用轻量悬浮及按压反馈。
- 动效不得延迟高频操作或干扰表格阅读。
- 禁止持续闪烁、强烈呼吸光和大范围背景运动。

## 8. 全局布局与导航

全站采用 **Focused Sidebar** 布局。

### 8.1 左侧导航

- 使用单层、可折叠侧栏。
- 首次进入系统时侧栏默认展开。
- 用户手动切换展开或折叠后，在本地记住该偏好，并在后续访问中恢复。
- 导航分为工作台、Agent、资源管理、系统管理。
- 展开状态显示图标与文字；折叠状态保留图标和悬浮提示。
- 当前页面通过紫色信号条、图标和文字色共同标识。
- Agent 编排页提供用户手动触发的画布专注模式。
- 专注模式隐藏侧栏和非必要顶栏；退出后恢复进入专注模式前的布局状态。

### 8.2 顶部状态栏

- 展示当前页面标题。
- 提供页面与功能命令中心入口。
- 命令中心支持按页面名称、功能名称和常用操作关键词检索。
- 用户通过命令结果跳转到对应页面，再在页面内完成具体操作。
- 命令中心不搜索后端业务数据，不新增统一搜索接口。
- 提供当前用户菜单和退出登录。

### 8.3 内容区

- 根据页面类型呈现仪表盘、数据表格、流程画布或对话工作区。
- 内容区保留统一的页头、间距和操作层级。
- 高频主操作固定在用户预期位置，危险操作置于普通操作之后。

## 9. 全局交互与状态

### 9.1 统一反馈

- 成功、失败和警告统一使用深色 Toast。
- 页面级请求使用骨架屏或局部加载态，避免整页空白。
- 空数据需要说明原因，并在适用时提供新建或刷新入口。
- 请求失败需要展示可理解的原因和重试操作。
- 普通接口失败不得导致整页崩溃。

### 9.2 表单

- 必填项、格式错误和关联资源错误需要就近提示。
- 提交期间禁用重复提交。
- 提交失败后保留用户输入。
- 存在未保存内容时，关闭弹窗或离开页面需要确认。

### 9.3 高风险操作

- 删除流程、资源和用户前必须二次确认。
- 确认内容必须说明目标对象和不可恢复后果。
- 禁止删除当前登录账号。

### 9.4 本地登录状态

- 登录成功后按现有方式保存本地登录标记与用户信息。
- 本地登录标记不存在或用户主动退出时返回登录页。
- 后端当前不提供 Token、会话续期或服务端登录失效接口，本次不增加相关能力。

### 9.5 页面与功能命令中心

- 顶部栏提供明确入口，用户通过点击打开。
- 本次不提供命令中心键盘快捷键。
- 搜索范围包括 13 个页面及其功能关键词。
- 搜索结果需要标明所属导航分组。
- 命令中心只负责页面跳转，不直接执行新增、刷新、删除等操作。
- 无匹配结果时提供可理解的空态，不请求后端业务数据。

## 10. 功能需求

### 10.1 登录

- 独立全屏深色布局，展示 ANN Agent Studio 字标与产品说明。
- 提供账号、密码和密码显隐控制。
- 保留管理员快捷登录入口；点击后立即使用现有默认管理员账号提交登录。
- 快捷登录与普通登录共用加载、成功和失败反馈。
- 登录成功后进入仪表盘。
- 登录失败时保留输入并提示失败原因。
- 未登录访问业务页面时返回登录页。
- 已登录用户访问登录页时进入仪表盘。

### 10.2 仪表盘

- 只展示现有统计接口真实计算的 7 项资源数量：Agent、客户端、MCP 工具、系统 Prompt、RAG 订单、Advisor 和模型。
- 不展示接口中暂时硬编码的今日请求数、成功率和运行中任务数。
- 不展示 Mock 趋势、虚构活动、健康状态或后端无法提供的数据。
- 提供 Agent 列表、Agent 编排和 Agent 对话快捷入口。
- 使用资源概览卡片和清晰分组表达当前资源规模。
- 加载失败时提供局部错误态和重新加载操作。
- 数据为空时展示空态，不使用虚假占位数字。

### 10.3 Agent 列表

- 展示 Agent 标识、名称、描述、渠道、策略和状态。
- 支持查询、刷新、加载和空数据反馈。
- 支持装配 Agent，并展示处理中、成功和失败状态。
- 提供前往流程编排和对话调试的入口。
- 关键标识支持复制。

### 10.4 Agent 编排

- 保留现有 Flowgram 自由画布。
- 保留开始、Agent、客户端、Advisor、模型、Prompt、MCP 工具、LLM、任务、条件、循环和结束共 12 类节点。
- 支持节点拖放、连线、选择、移动、删除、复制粘贴、分组和批注。
- 支持缩放、小地图、自动布局及现有快捷键。
- 支持新建流程、选择已有流程、加载、保存和删除配置。
- 删除配置前必须二次确认。
- 节点属性区使用适合深色背景的分组表单。
- 模型、Prompt、Advisor、MCP 等节点选项来自对应资源管理数据。
- 对应资源为空时，引导用户前往资源页面配置。
- 支持画布专注模式，最大化可操作空间。
- 存在未保存修改时，切换页面、新建流程或加载其他流程前显示自定义确认。
- 存在未保存修改时，刷新或关闭浏览器触发浏览器原生离开确认。
- 加载或保存失败时保留当前画布内容并允许重试。

### 10.5 Agent 对话

- 左侧选择可用 Agent，右侧展示消息流和输入区。
- 使用现有流式响应能力逐段展示 Agent 回复。
- 支持创建新会话、发送消息、停止生成和失败重试。
- 发送期间展示运行状态并防止重复提交。
- 用户消息与 Agent 消息使用不同方向和视觉层级。
- 错误与超时以消息级状态展示，不覆盖已有对话。
- 本次不增加服务端会话历史，刷新后不保证恢复消息。

### 10.6 统一资源管理体验

客户端、模型 API、模型、Advisor、系统 Prompt、MCP 工具、RAG 订单和用户管理遵循以下统一要求：

- 页头展示页面标题、简短说明和主操作。
- 提供与模块字段匹配的搜索、状态筛选和重置。
- 表格支持加载、空数据、错误和横向滚动。
- 按模块实际字段展示主标识、名称（如有）、状态、创建时间、更新时间和操作列。
- 客户端、模型、RAG 订单和用户等简单表单使用深色居中弹窗。
- 模型 API、Advisor、系统 Prompt 和 MCP 工具等复杂表单使用深色右侧抽屉。
- 删除必须二次确认，成功后刷新列表，失败时保留上下文。
- 状态统一显示为启用或禁用。
- 敏感字段默认脱敏，仅在明确操作后复制。
- 操作顺序遵循常用操作优先、危险操作最后。

### 10.7 客户端管理

- 维护客户端标识、名称、描述和状态。
- 支持现有查询、新增、编辑和删除能力。

### 10.8 模型 API 管理

- 维护 API 标识、基础地址、Key、对话补全路径、向量嵌入路径和状态。
- API Key 在列表中始终脱敏，只支持主动复制，不通过悬浮或点击直接展示完整内容。
- 编辑抽屉中的 API Key 输入支持显隐切换，默认隐藏。
- 支持现有查询、新增、编辑和删除能力。
- 后端当前没有 API 加载或装配接口，本次不提供“加载 API”操作。

### 10.9 模型管理

- 维护模型标识、名称、所属 API、模型类型、模型用途和状态。
- 关联 API 不存在时阻止保存并提示。
- 支持现有查询、新增、编辑和删除能力。

### 10.10 Advisor 管理

- 维护 Advisor 标识、名称、类型、顺序、扩展参数和状态。
- 扩展参数必须满足现有格式要求。
- 支持现有查询、新增、编辑和删除能力。

### 10.11 系统 Prompt 管理

- 维护 Prompt 标识、名称、内容、描述和状态。
- 长内容支持独立查看与编辑。
- 支持现有查询、新增、编辑和删除能力。

### 10.12 MCP 工具管理

- 维护 MCP 标识、名称、传输类型、传输配置、请求超时和状态。
- 传输配置必须为有效 JSON。
- 支持现有查询、新增、编辑和删除能力。

### 10.13 RAG 订单管理

- 维护 RAG 标识、名称、知识标签和状态。
- 保留知识库文件上传能力。
- 支持 TXT、PDF、DOC、DOCX 和 Markdown 文件。
- 单个文件不得超过 10MB。
- 上传失败后保留当前选择并允许重新提交。
- 支持现有查询、新增、编辑和删除能力。

### 10.14 用户管理

- 支持用户查询、新增、编辑、启禁用和删除。
- 新增用户必须填写密码。
- 禁止删除当前登录账号。
- 用户状态需要清晰展示。

## 11. 资源关联规则

- Agent 编排中的资源选择只展示当前可用数据。
- 资源不存在、被禁用或已删除时必须明确提示。
- 关联资源缺失时不得静默保存无效配置。
- 本次不增加跨资源批量编辑、批量删除或审批能力。

7. 7 个资源管理模块及用户管理的现有查询、新增、编辑、删除等能力保持可用。
8. 模型 API 密钥复制、RAG 文件上传等有现有接口或纯前端支持的模块特有功能保持可用。
9. 所有接口区域具备加载、空数据、失败和重试反馈。
10. 删除、未保存离开等高风险操作具备确认机制。
11. 在 1280、1440 和 1920px 宽度下无主要内容遮挡、重叠或不可操作。
12. 文字、状态与键盘焦点在深色背景下清晰可辨。
13. 前端构建通过，主要页面无阻断性控制台错误。
14. 页面与功能命令中心可按页面名称和功能关键词完成导航，且不依赖新增后端接口。

## 15. 不在本次范围

- 后端接口或数据库改造。
- 手机端与完整平板适配。
- 浅色主题和主题切换。
- 完整国际化。
- 角色权限与细粒度授权。
- 新增后端统计指标。
- 对话历史持久化。
- 批量资源操作和审批流。
- 生产部署架构调整。
