# Agent 编排画布点阵降噪设计

## 背景与目标

当前 Agent 编排画布使用 24px 间距、高对比度的密集点阵。大面积显示时容易产生闪烁和眩目感，也会与节点、端口和连线争夺视觉注意力。

本次调整的目标是保留画布的空间定位能力，同时让背景退到视觉第三层，使节点和连线成为明确焦点。

## 设计方案

采用均匀稀疏低亮度点阵：

- 点阵间距由 `24px` 调整为 `42px`。
- 点阵透明度由 `28%` 调整为约 `14%`。
- 点径由 `0.8px` 调整为 `0.65px`。
- 顶部紫色径向光晕透明度由 `8%` 调整为 `5%`。
- 不增加动画、渐隐遮罩或多级主点。
- 节点、端口、连线、缩略图和工具栏样式保持不变。

## 实现范围

仅调整 `frontend/src/styles/index.css` 中 `.ann-workflow-theme .gedit-playground` 的两层背景参数，不修改 Flowgram 数据、交互逻辑或组件结构。

## 验收标准

- 在常用桌面分辨率下，点阵不再呈现密集闪烁感。
- 点阵仍能辅助判断节点移动距离和画布空间位置。
- 节点文字、端口和连线的视觉优先级明显高于背景。
- 画布继续保持深色、高级且具有轻微科技感的整体风格。
- 主题契约测试、TypeScript 检查和生产构建继续通过。
- 浏览器计算样式显示点阵间距为 `42px 42px`，并通过截图完成视觉复查。

## 非目标

- 不提供画布背景切换选项。
- 不引入动态网格缩放。
- 不改变其他页面的背景纹理。
- 不调整节点布局、缩放行为或快捷操作。
